### Введение

******

3-Terra Player предоставляет встроенный контроллер и частную службу фонового воспроизведения для аудиофайлов, открытых из файлового менеджера. Он также принимает запросы Android ACTION_VIEW только для чтения для content URI с аудио MIME-типом.

******

### Возможности

******

- Регистрирует действия `play-audio` и `play-audio-selection` через Explorer Action v12 для всех распознанных хостом аудио MIME-типов и 19 известных расширений.
- Воспроизводит аудио с помощью Media3 ExoPlayer и MediaSessionService, поддерживая аудиофокус, обработку отключения выхода, локальный режим пробуждения, фоновое воспроизведение и системные элементы управления мультимедиа.
- Предоставляет экран с обложкой, тегами, технической информацией, перемоткой, переходами на 10 секунд, режимами по порядку / случайно / повтор одного и скоростью от 0,5x до 2x.
- Воспроизводит до 128 явно выбранных аудиофайлов в порядке хоста, с командами предыдущий / следующий и очередью для перехода или удаления треков.
- Включает таймер сна службы с пресетами, своим временем, остановкой после текущего трека, затуханием за последние пять секунд и A-B повтором.
- Запоминает только последний открытый файл и его позицию, сразу заменяет запись при открытии другого и синхронизирует текущие метаданные и команды с системой.
- Предоставляет экран выбора до 128 документов и принимает URI `content` ACTION_VIEW только для чтения, включая устаревшие MIME-псевдонимы WMA.
- При ошибке декодера предлагает открыть файл в другом совместимом приложении и исключает этот плагин, чтобы предотвратить цикл.
- При открытии одного файла из Проводника через Host Session для запроса обнаруживает ограниченную, естественно отсортированную очередь читаемых соседних аудиофайлов; явный множественный выбор сохраняет порядок хоста.
- Создаёт контрастную палитру из одного цвета, следует AutoJs6 и предлагает 19 цветов Material 500 и свой RGB; настройки охватывают язык, ночь, продолжение, обновления, историю и сведения о приложении.

******

### Расширения Проводника

******

Каталог Проводника объявляет `audio/*` и использует эти расширения для старых или неполных таблиц MIME:

```text
aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave, wma
```

Совпадение расширения не гарантирует декодирование. Фактическое воспроизведение зависит от Media3, платформы Android, кодеков устройства и содержимого файла.

******

### Поведение хоста

******

После установки и включения плагина в AutoJs6 менеджер показывает Воспроизвести аудио для одного файла и Воспроизвести выбранное аудио на панели множественного выбора. Однофайловый вход начинает с выбранной дорожки и может обнаружить читаемые непосредственные соседние аудиофайлы в естественном порядке; явный множественный выбор сохраняет порядок хоста.

Когда плагин отсутствует, это действие не отображается. Хост сохраняет существующий внешний поток ACTION_VIEW только для чтения для аудиофайлов, поэтому другое установленное аудиоприложение может обработать файл. Если совместимого внешнего приложения нет, хост не получает заменяющий интерфейс воспроизведения.

******

### Интерфейс плагина

******

Хост обнаруживает и запускает плагин со следующими идентификаторами:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: audio-player
engine: explorer-action
variant: default
Explorer action ids: play-audio (single) / play-audio-selection (multiple, up to 128)
Explorer protocol version: 12 (accepts compatible read-only v4–v12 requests)
Explorer MIME types: [audio/*]
Android VIEW action: android.intent.action.VIEW
Android VIEW MIME type: audio/* plus legacy WMA MIME aliases
required host build: 5276
```

Версия 1.4.0 предоставляет действия v12 только для чтения, ограниченный доступ к соседям, автономный выбор документов и точки входа Android для аудио / WMA. Без Host Session проигрывается только выбранный файл.

Для обнаружения в той же папке требуются AutoJs6 6.8.0 build 5276 или новее и Explorer Action v12; будущие возможности плагина не повысят это требование.

### Безопасность

******

Плагин не запрашивает хранилище и не записывает исходные файлы. Интернет используется только для ручной или ежедневной проверки выпусков GitHub. Подписанная точка строго проверяет v12, TARGETS, ClipData, метаданные и чтение; Host Session остаётся привязанной к UID и нерекурсивной, а публичные точки — только для чтения.

******

### Ограничения безопасности

******

- Одиночное действие начинает ровно с одного выбранного файла и может сформировать ограниченную очередь читаемых непосредственных соседних аудиофайлов; действие выбора принимает от 1 до 128 уникальных файлов и сохраняет порядок.
- Запросы Проводника с заявленным размером больше 8 TiB отклоняются.
- Действия сопоставляются по распознанному аудио MIME или явному списку расширений и нормализуют и проверяют каждую цель.
- Обнаружение соседей нерекурсивно и доступно только через принадлежащую хосту сессию запроса; плагин никогда не угадывает соседний URI и не получает путь файловой системы.
- Публичная точка Android требует ACTION_VIEW, URI `content`, поддерживаемый аудио- или WMA-MIME и разрешение чтения.
- Разрешение уведомлений необязательно. Отказ скрывает элементы управления в панели уведомлений, но не блокирует воспроизведение.
- Воспроизведение безопасно завершается при окончании или ошибке декодера. Внешний резервный вариант передает только новое разрешение чтения и исключает этот плагин.

# v1.4.0

###### 2026/08/29

* `Функция` Системное медиасообщение теперь содержит отдельные действия предыдущего и следующего трека, переключения перемешивания и выхода, а также прозрачный монохромный значок приложения; подсветка перемешивания синхронизируется с воспроизведением
* `Исправление` AutoJs6 больше не помечает плагин как ошибочный и не отключает его при обнаружении сведений о плагине и Explorer Action, поскольку два протокола Binder теперь используют отдельные службы
* `Исправление` Очистка очереди удаляет устаревшие сведения о треке и фоновый сеанс, отключает воспроизведение, поиск, очередь, скорость, таймер и A-B и показывает явное пустое состояние вместо обработки бесполезных нажатий
* `Исправление` Тень основной кнопки воспроизведения больше не обрезается нижней областью, а отключенное состояние использует отчетливые приглушенные цвета; переключатели, множественный выбор, прогресс и кнопки диалогов теперь следуют динамической теме
* `Улучшение` Приложение и плагин переименованы в непереводимое 3-Terra Player, а пространства имен и символы исходного кода переведены на формы three / Three; опубликованный ID приложения сохранен для обновлений и существующих настроек
* `Улучшение` Ярлык палитры на панели проигрывателя заменен меню из трех точек с единственным пунктом настроек без изменения существующего интервала под элементами воспроизведения

# v1.3.0

###### 2026/08/29

* `Функция` Добавлены экран запуска и автономный проигрыватель нескольких файлов, а также отдельные настройки языка, ночного режима, цвета темы, продолжения, обновлений, истории выпусков и сведений о приложении и разработчике
* `Функция` Язык, ночной режим и исходный цвет по умолчанию следуют AutoJs6 через официальный контракт только для чтения; если хост недоступен, варианты остаются видимыми, но отключёнными, и используются значения приложения
* `Функция` Добавлены ручная и ежедневная автоматическая проверка обновлений, управление игнорируемыми версиями и локализованная встроенная история выпусков
* `Исправление` Исправлено постоянное сообщение Host color unavailable: открыт защищённый вход службы информации о плагине, необходимый поставщику настроек хоста
* `Исправление` Действия Проводника теперь объявляют аудио MIME вместе с 19 известными расширениями, включая WMA, чтобы любой распознанный хостом аудиофайл сразу открывался в плагине
* `Улучшение` Продолжение запоминает ровно один последний открытый файл, немедленно удаляет старую запись при открытии другого и не сохраняет завершённое воспроизведение
* `Улучшение` Область метаданных стабильно занимает три строки и дополняет частоту и битрейт из выбранной дорожки в порядке 44.1 kHz · MP3 · 128 kbps
* `Улучшение` A-B теперь использует понятный цикл из трёх нажатий: задать A, задать B и очистить; нижние элементы получили отступ, одинаковый размер и точное вертикальное центрирование значков

# v1.2.2

###### 2026/08/27

* `Исправление` Воспроизведение из проводника больше не завершается ошибкой после обновления плагина, если запущенный файловый менеджер AutoJs6 всё ещё отправляет кэшированное действие протокола v4; шлюз принимает совместимый пакет только для чтения v4–v12 и по-прежнему объявляет v12
* `Исправление` Заявленные аудиорасширения больше не отклоняются, когда таблица MIME Android или производителя возвращает подстановочный либо application-тип; белый список расширений теперь предоставляет стабильный канонический аудио MIME-тип
* `Улучшение` Отклонённые запросы Explorer теперь записывают безопасный для конфиденциальности код причины без имён файлов, отображаемых путей и URI, что позволяет напрямую диагностировать будущие расхождения контракта

******

```powershell
.\gradlew.bat :app:assembleDebug
```

```powershell

```

Параметры сборки берутся из `version.properties`. Текущий минимальный SDK равен 24, целевой SDK равен 36.
