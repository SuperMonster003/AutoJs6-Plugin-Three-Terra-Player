# 오디오 플레이어

오디오 플레이어는 파일 관리자가 이미 인식하는 다음 오디오 파일 확장자에 앱 내 컨트롤러와 백그라운드 재생을 추가합니다:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave`

플러그인이 설치되면 파일 관리자 기본 작업에서 오디오 재생을 선택하세요. 플러그인이 없으면 호스트는 기존 읽기 전용 외부 ACTION_VIEW 흐름을 유지하므로 설치된 다른 오디오 앱이 파일을 열 수 있습니다.

재생은 Media3를 사용하며 백그라운드에서 계속할 수 있습니다. Android 13+의 알림 권한은 선택 사항이며 알림 창 제어에만 영향을 줍니다. 거부해도 재생은 차단되지 않습니다.

호스트 빌드 5269 이상이 필요합니다.

보안 및 개인정보 제한:

- 파일 관리자 진입점에는 호스트 서명 권한이 필요하며 프로토콜 v2, 두 content URI, ClipData, 파일 메타데이터 및 읽기 전용 권한을 검증합니다.
- 독립 Android 진입점은 `audio/*`를 가진 읽기 전용 `content` URI만 받고 호출자의 extras나 광범위한 권한을 전달하지 않습니다.
- 저장소 또는 네트워크 권한을 요청하지 않으며 원본 파일에 쓰지 않습니다.
- 파일 확장자 일치는 디코딩을 보장하지 않습니다. 지원 여부는 Media3, Android, 기기 코덱 및 파일 내용에 따라 달라집니다.
- 디코더 오류 후 다른 호환 앱으로 파일을 열 수 있으며 선택 화면에서 이 플러그인을 제외합니다.
