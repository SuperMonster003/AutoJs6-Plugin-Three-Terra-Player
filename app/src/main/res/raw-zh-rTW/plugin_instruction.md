# 音訊播放器

音訊播放器同時是 AutoJs6 外掛程式與獨立應用程式, 為檔案管理器辨識的所有音訊 MIME 類型提供應用程式內控制介面和背景播放, 並明確覆蓋以下副檔名:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave, wma`

安裝外掛程式後, 對單一檔案選擇播放音訊會從該曲目開始, 並可自動尋找可讀的直接同層音訊, 按自然順序組成有界佇列. 明確選取 1 至 128 個檔案並選擇播放所選音訊時, 仍保持主程式選取順序. 缺少外掛程式時, 主程式保留單一檔案唯讀外部 ACTION_VIEW 流程.

啟動頁面可在沒有 AutoJs6 的情況下開啟最多 128 個音訊文件. 獨立設定提供語言、夜間模式、主題色、續播、更新檢查、已忽略版本、發行歷史及應用程式與開發者資訊. 主程式受保護設定協定可用時, 語言、夜間模式與主題色預設跟隨 AutoJs6.

播放使用 Media3, 並可在背景繼續. 播放器提供上一首 / 下一首, 可編輯播放佇列, 順序 / 隨機 / 單曲循環, 睡眠計時器, A-B 區間循環及倍速. 續播僅記憶最近開啟的一個檔案; 開啟其他檔案時立即丟棄舊位置, 播放完畢時絕不儲存. Android 13+ 通知權限是可選權限, 只影響通知欄控制.

同資料夾尋找需要 AutoJs6 6.8.0 build 5276+ 及 Explorer Action v12; 後續外掛程式功能不會提高此基線. 不提供可選工作階段功能的主程式仍僅播放所選檔案.

安全和隱私限制:

- 檔案管理器入口要求主程式簽章權限, 並驗證通訊協定 v12, 有序目標與 ClipData, 識別碼, 父子關係, 檔案中繼資料, 宣告功能和唯讀授權.
- 獨立 Android 入口只接受音訊或舊式 WMA MIME 類型的唯讀 `content` URI, 不會轉交呼叫端 extras 或廣泛授權.
- 應用程式不要求儲存權限, 也不會寫入來源檔案. 網際網路僅用於使用者主動或每日 GitHub 發行版檢查.
- 請求級 Host Session 由主程式綁定至外掛程式 UID, 僅允許非遞迴列出所選檔案的直接上層資料夾並開啟所選檔案或可讀直接同層音訊. 播放端只接收不透明合成路由, 不接收檔案系統路徑, 也絕不猜測同層 URI.
- 檔案副檔名比對不保證可以解碼. 支援情況取決於 Media3, Android, 裝置編解碼器和檔案內容.
- 解碼錯誤後可使用其他相容應用程式開啟檔案, 並在選擇介面中排除本外掛程式.
