# 오디오 플레이어

오디오 플레이어는 파일 관리자가 이미 인식하는 다음 오디오 파일 확장자에 앱 내 컨트롤러와 백그라운드 재생을 추가합니다:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave`

설치 후 파일 하나에서 오디오 재생을 선택하면 해당 곡에서 시작해 읽을 수 있는 직접 형제 오디오를 자연 정렬한 제한된 재생목록으로 찾을 수 있습니다. 1개에서 128개 파일을 명시적으로 선택하면 호스트 선택 순서를 유지합니다. 플러그인이 없으면 단일 파일용 읽기 전용 외부 ACTION_VIEW 흐름을 유지합니다.

재생은 Media3를 사용하며 백그라운드에서 계속할 수 있습니다. 이전 / 다음, 편집 가능한 대기열, 순차 / 셔플 / 한 곡 반복, 취침 타이머, A-B 반복, 배속과 곡별 이어듣기를 제공합니다. Android 13+ 알림 권한은 선택 사항입니다.

같은 폴더 검색에는 AutoJs6 6.8.0 build 5276 이상과 Explorer Action v12가 필요하며 이후 기능에서도 이 기준을 높이지 않습니다. 선택적 세션이 없는 호스트는 선택 파일만 재생합니다.

보안 및 개인정보 제한:

- 파일 관리자 진입점에는 호스트 서명 권한이 필요하며 프로토콜 v12, 순서가 있는 대상과 ClipData, 식별자, 상위 관계, 메타데이터, 선언된 기능 및 읽기 전용 권한을 검증합니다.
- 독립 Android 진입점은 `audio/*`를 가진 읽기 전용 `content` URI만 받고 호출자의 extras나 광범위한 권한을 전달하지 않습니다.
- 저장소 또는 인터넷 접근 권한을 요청하지 않으며 원본 파일에 쓰지 않습니다. Media3가 일반 `ACCESS_NETWORK_STATE` 권한을 포함하지만 APK에는 `INTERNET` 권한이 없습니다.
- 요청 범위 Host Session은 플러그인 UID에 고정되며 선택 파일의 직접 상위 폴더를 비재귀적으로 나열하고 선택 파일 또는 읽을 수 있는 직접 형제 오디오를 여는 것만 허용합니다. 재생은 불투명 합성 경로만 받고 파일 시스템 경로나 형제 URI를 추측하지 않습니다.
- 파일 확장자 일치는 디코딩을 보장하지 않습니다. 지원 여부는 Media3, Android, 기기 코덱 및 파일 내용에 따라 달라집니다.
- 디코더 오류 후 다른 호환 앱으로 파일을 열 수 있으며 선택 화면에서 이 플러그인을 제외합니다.
