# v1.5.0 回归记录

记录日期: 2026/08/31

## 交付范围

- 设置页“语言”和“夜间模式”选择项统一使用 Material `Body1` 语义的 `16sp` 字号, 同一适配器也用于本版本新增的高级播放设置对话框.
- 播放器从内嵌专辑封面提取主色, 为亮色 / 暗色模式生成可读调色板; 无封面, 透明封面或解码失败时回退当前用户主题或 AutoJs6 主题.
- 播放器及独立应用各页面统一启用 edge-to-edge, 显式消费状态栏, 刘海, 横向安全区与底部手势 / 导航栏 Insets.
- 设置页增加默认倍速, 快退快进步长和队列完成行为; 新值持久化并即时应用到当前播放会话.
- 增加封面入场、播放状态切换动画和关键播放操作触感反馈, 同时尊重系统动画与触感开关.
- 完成播放可视化技术调研和不接入播放器的纯 JVM PCM/RMS 聚合原型, 结论见 [播放可视化可行性调研](playback-visualization-feasibility.md).
