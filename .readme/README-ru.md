### Введение

******

Audio Player предоставляет встроенный контроллер и частную службу фонового воспроизведения для аудиофайлов, открытых из файлового менеджера. Он также принимает запросы Android ACTION_VIEW только для чтения для content URI с аудио MIME-типом.

******

### Возможности

******

- Регистрирует действие для одного файла `play-audio` и упорядоченное действие множественного выбора `play-audio-selection` через протокол Explorer Action v12 для 18 аудиорасширений хоста.
- Воспроизводит аудио с помощью Media3 ExoPlayer и MediaSessionService, поддерживая аудиофокус, обработку отключения выхода, локальный режим пробуждения, фоновое воспроизведение и системные элементы управления мультимедиа.
- Предоставляет экран с обложкой, тегами, технической информацией, перемоткой, переходами на 10 секунд, режимами по порядку / случайно / повтор одного и скоростью от 0,5x до 2x.
- Воспроизводит до 128 явно выбранных аудиофайлов в порядке хоста, с командами предыдущий / следующий и очередью для перехода или удаления треков.
- Включает таймер сна службы с пресетами, своим временем, остановкой после текущего трека, затуханием за последние пять секунд и A-B повтором.
- Запоминает позицию каждого трека и отражает в системных медиа-интерфейсах название, обложку, предыдущий / следующий и переходы на 10 секунд.
- Принимает независимые запросы Android ACTION_VIEW для URI `content` только для чтения с `audio/*`, удаляя extras вызывающей стороны и широкие разрешения URI.
- При ошибке декодера предлагает открыть файл в другом совместимом приложении и исключает этот плагин, чтобы предотвратить цикл.
- При открытии одного файла из Проводника через Host Session для запроса обнаруживает ограниченную, естественно отсортированную очередь читаемых соседних аудиофайлов; явный множественный выбор сохраняет порядок хоста.
- Создаёт контрастную светлую и тёмную палитру из одного исходного цвета, по умолчанию следует AutoJs6 и предлагает 19 локализованных цветов Material 500, а также свой RGB-цвет с живым предпросмотром.

### Расширения Проводника

******

Каталог Проводника намеренно сопоставляет только следующие расширения и объявляет пустой список MIME-типов:

```text
aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave
```

Совпадение расширения не гарантирует декодирование. Фактическое воспроизведение зависит от Media3, платформы Android, кодеков устройства и содержимого файла.

******

### Поведение хоста

******

После установки менеджер показывает Воспроизвести аудио для одного файла и Воспроизвести выбранное аудио на панели множественного выбора. Однофайловый вход начинает с выбранной дорожки и может обнаружить читаемые непосредственные соседние аудиофайлы в естественном порядке; явный множественный выбор сохраняет порядок хоста.

Когда плагин отсутствует, это действие не отображается. Хост сохраняет существующий внешний поток ACTION_VIEW только для чтения для аудиофайлов, поэтому другое установленное аудиоприложение может обработать файл. Если совместимого внешнего приложения нет, хост не получает заменяющий интерфейс воспроизведения.

******

### Интерфейс плагина

******

Хост обнаруживает и запускает плагин со следующими идентификаторами:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: audio-player
engine: explorer-action
variant: default
Explorer action ids: play-audio (single) / play-audio-selection (multiple, up to 128)
Explorer protocol version: 4
Explorer MIME types: []
Android VIEW action: android.intent.action.VIEW
Android VIEW MIME type: audio/*
required host build: 5276
```

Версия 1.2.1 предоставляет основное однофайловое действие только для чтения по протоколу v12, способное получить возможность прямого доступа к соседям на время запроса, и сохраняет упорядоченное действие множественного выбора. Независимая точка входа Android остается однофайловой и принимает `audio/*`. Хосты без необязательной Host Session воспроизводят только выбранный файл.

Для обнаружения в той же папке требуются AutoJs6 6.8.0 build 5276 или новее и Explorer Action v12; будущие возможности плагина не повысят это требование.

### Безопасность

******

Плагин не запрашивает разрешения хранилища или доступа в Интернет. Защищенная подписью точка входа строго проверяет протокол v12, упорядоченные TARGETS и ClipData, идентификаторы, связь с родителем, метаданные и флаги чтения. Необязательная Host Session привязывается хостом к UID плагина и может только перечислять непосредственного родителя выбранного файла и открывать выбранный файл либо читаемый непосредственный соседний файл; компоненты воспроизведения получают непрозрачные синтетические маршруты, но не пути файловой системы. Публичная точка Android остается однофайловой и только для чтения.

******

### Ограничения безопасности

******

- Одиночное действие начинает ровно с одного выбранного файла и может сформировать ограниченную очередь читаемых непосредственных соседних аудиофайлов; действие выбора принимает от 1 до 128 уникальных файлов и сохраняет порядок.
- Запросы Проводника с заявленным размером больше 8 TiB отклоняются.
- Действие Проводника выбирается только по расширению файла и при запуске также проверяет аудио MIME-тип.
- Обнаружение соседей нерекурсивно и доступно только через принадлежащую хосту сессию запроса; плагин никогда не угадывает соседний URI и не получает путь файловой системы.
- Публичная точка входа Android требует ACTION_VIEW, URI `content`, `audio/*` и разрешение чтения.
- Разрешение уведомлений необязательно. Отказ скрывает элементы управления в панели уведомлений, но не блокирует воспроизведение.
- Воспроизведение безопасно завершается при окончании или ошибке декодера. Внешний резервный вариант передает только новое разрешение чтения и исключает этот плагин.

### История выпусков

******

# v1.2.2

###### 2026/08/27

* `Исправление` Воспроизведение из проводника больше не завершается ошибкой после обновления плагина, если запущенный файловый менеджер AutoJs6 всё ещё отправляет кэшированное действие протокола v4; шлюз принимает совместимый пакет только для чтения v4–v12 и по-прежнему объявляет v12
* `Исправление` Заявленные аудиорасширения больше не отклоняются, когда таблица MIME Android или производителя возвращает подстановочный либо application-тип; белый список расширений теперь предоставляет стабильный канонический аудио MIME-тип
* `Улучшение` Отклонённые запросы Explorer теперь записывают безопасный для конфиденциальности код причины без имён файлов, отображаемых путей и URI, что позволяет напрямую диагностировать будущие расхождения контракта

# v1.2.1

###### 2026/08/27

* `Функция` Действие «Воспроизвести аудио» для одного файла теперь обнаруживает через Explorer Action v12 до 128 читаемых аудиофайлов в той же папке и строит естественно отсортированную очередь с выбранной дорожки
* `Исправление` API 24 больше не отклоняет корректный запрос Explorer, когда Android добавляет из манифеста шлюзовой Activity не связанный с разрешениями флаг FLAG_ACTIVITY_EXCLUDE_FROM_RECENTS
* `Исправление` Автоматический переход к соседней дорожке больше не вызывает сбой при пересоздании обратного Intent MediaSession; исходно разрешённая цель остаётся якорем Host Session независимо от активного элемента очереди
* `Улучшение` Выбранная дорожка сохраняет исходный content URI, а соседние дорожки передаются только через файловые дескрипторы ограниченной запросом Host Session; URI не угадываются и не добавляется рекурсивный доступ, запись, доступ к хранилищу или постоянный доступ
* `Улучшение` Фильтрация аудиорасширений исключает из очереди видео .mp4 с тем же именем, что и аудио .m4a, а существующая явная очередь множественного выбора остаётся без изменений
* `Улучшение` Владение Host Session передаётся фоновой службе воспроизведения, которая закрывает её при замене очереди, ошибке запуска, завершении воспроизведения или уничтожении службы
* `Зависимость` Встроенный Explorer Action API обновлён с протокола v4 до обратно совместимого расширения v12 для чтения соседних файлов при сохранении минимальной сборки хоста 5276

# v1.2.0

###### 2026/08/27

* `Функция` Поддержка Explorer Action v4 и новое упорядоченное действие выбора, создающее очередь из явно выбранных аудиофайлов количеством до 128
* `Функция` Нативный список Media3 с предыдущим / следующим, панелью перехода и удаления треков и режимами по порядку / случайно / повтор одного
* `Функция` Таймер сна службы на 15 / 30 / 60 минут, со своим временем, остановкой после текущего трека и затуханием за последние пять секунд
* `Функция` A-B повтор выбранного интервала
* `Улучшение` Системные медиа-команды теперь показывают предыдущий, следующий и переходы на 10 секунд; метаданные и позиция продолжения следуют текущему треку
* `Улучшение` Проверка Explorer охватывает упорядоченные TARGETS и ClipData, уникальные идентификаторы, сессию хоста и каждый выбранный файл без расширения прав чтения
* `Улучшение` Задокументировано, что родительский URI FileProvider не перечисляет дочерние элементы; поиск соседей и угадывание URI отключены, безопасный путь — явный выбор
* `Зависимость` Встроенный Explorer Action API обновлен с протокола v2 до v4, минимальная сборка хоста повышена до 5276
* `Зависимость` Добавлен AndroidX RecyclerView 1.4.0
