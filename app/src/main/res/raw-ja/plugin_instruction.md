# 音声プレーヤー

音声プレーヤーはAutoJs6プラグインと独立アプリの両方として動作します. ファイルマネージャーが認識するすべての音声MIMEタイプにアプリ内コントローラーとバックグラウンド再生を追加し, 次の拡張子を明示的に対象とします:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave, wma`

インストール後, 1ファイルで音声を再生を選ぶとその曲から開始し, 読み取り可能な直接同階層の音声を自然順の上限付きキューとして検出できます. 1から128ファイルの明示的な選択ではホストの選択順を維持します. プラグインがない場合は1ファイル用の読み取り専用外部ACTION_VIEWフローを維持します.

ランチャーはAutoJs6なしで最大128個の音声ドキュメントを開けます. 独立設定には言語, ナイトモード, テーマ色, 再開, 更新確認, 無視したバージョン, リリース履歴, アプリと開発者情報があります. 保護された設定契約が利用可能な場合, 言語, ナイトモード, テーマ色は既定でAutoJs6に従います.

再生にはMedia3を使い, バックグラウンドでも継続できます. 前 / 次, 編集可能なキュー, 順次 / シャッフル / 1曲リピート, スリープタイマー, A-Bリピート, 速度調整を提供します. 再開位置は最後に開いた1ファイルだけを記憶し, 別のファイルを開いた時点で破棄され, 再生完了時は保存されません. Android 13+の通知権限は任意です.

同一フォルダー検出には AutoJs6 6.8.0 build 5276 以降と Explorer Action v12 が必要で, 今後の機能でもこの基準は引き上げません. 任意のセッションがないホストでは選択ファイルだけを再生します.

セキュリティとプライバシーの制限:

- ファイルマネージャー入口にはホスト署名権限が必要で, プロトコルv12, 順序付き対象とClipData, 識別子, 親子関係, メタデータ, 宣言された機能, 読み取り専用権限を検証します.
- 独立したAndroid入口は音声または従来のWMA MIMEタイプを持つ読み取り専用 `content` URIだけを受け付け, 呼び出し元のextrasや広範な権限を転送しません.
- ストレージ権限を要求せず, 元ファイルへ書き込みません. インターネットはユーザー操作または日次のGitHubリリース確認だけに使用します.
- リクエスト単位のHost SessionはプラグインUIDに固定され, 選択ファイルの直接の親を非再帰で列挙し, 選択ファイルまたは読み取り可能な直接同階層音声を開くことだけを許可します. 再生は不透明な合成ルートだけを受け取り, ファイルシステムパスも同階層URIの推測もありません.
- 拡張子の一致はデコードを保証しません. 対応状況はMedia3, Android, 端末のコーデック, ファイル内容に依存します.
- デコーダーエラー後は別の対応アプリでファイルを開くことができ, 選択画面からこのプラグインを除外します.
