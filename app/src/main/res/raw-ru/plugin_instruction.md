# 3-Terra Player

Аудиоплеер работает и как плагин AutoJs6, и как автономное приложение. Он добавляет контроллер и фоновое воспроизведение для всех аудиотипов MIME, распознаваемых менеджером, с явной поддержкой расширений:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave, wma`

После установки Воспроизвести аудио для одного файла начинает с этой дорожки и может обнаружить ограниченную естественно отсортированную очередь читаемых непосредственных соседних аудиофайлов. Явный выбор от 1 до 128 файлов сохраняет порядок хоста. Без плагина хост сохраняет однофайловый внешний поток ACTION_VIEW только для чтения.

Запускаемая страница открывает до 128 аудиодокументов без AutoJs6. Автономные настройки включают язык, ночной режим, цвет темы, продолжение, проверку обновлений, игнорируемые версии, историю выпусков и сведения о приложении и разработчике. Язык, ночной режим и цвет по умолчанию следуют AutoJs6, когда его защищённый контракт доступен.

Воспроизведение использует Media3 и продолжается в фоне. Доступны предыдущий / следующий, редактируемая очередь, режимы по порядку / случайно / повтор одного, таймер сна, A-B повтор и скорость. Продолжение запоминает только последний открытый файл, удаляет эту позицию при открытии другого файла и никогда не сохраняет завершённое воспроизведение. Разрешение уведомлений Android 13+ необязательно.

Для обнаружения в той же папке требуются AutoJs6 6.8.0 build 5276 или новее и Explorer Action v12; будущие возможности не повысят этот порог. Хосты без необязательного сеанса воспроизводят только выбранный файл.

Ограничения безопасности и конфиденциальности:

- Точка входа требует подпись хоста и проверяет протокол v12, упорядоченные цели и ClipData, идентификаторы, связь с родителем, метаданные, заявленные возможности и права только для чтения.
- Независимая точка входа Android принимает только URI `content` для чтения с аудио- или устаревшим WMA MIME-типом и не передает extras вызывающей стороны или широкие разрешения.
- Приложение не запрашивает доступ к хранилищу и не записывает исходный файл. Интернет используется только для ручной или ежедневной проверки выпусков GitHub.
- Host Session для запроса привязана к UID плагина и позволяет только нерекурсивно перечислять непосредственного родителя выбранного файла и открывать выбранный файл либо читаемый непосредственный соседний аудиофайл. Проигрыватель получает непрозрачные синтетические маршруты, но не пути файловой системы и не угадывает соседний URI.
- Совпадение расширения не гарантирует декодирование. Поддержка зависит от Media3, Android, кодеков устройства и содержимого файла.
- После ошибки декодера файл можно открыть в другом совместимом приложении, а этот плагин исключается из выбора.
