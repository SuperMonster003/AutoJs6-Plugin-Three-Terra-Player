# Аудиоплеер

Аудиоплеер добавляет встроенный контроллер и фоновое воспроизведение для следующих расширений, уже распознаваемых Проводником AutoJs6:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave`

Когда плагин установлен, выберите Воспроизвести аудио среди основных действий Проводника. Когда плагин отсутствует, AutoJs6 сохраняет существующий внешний поток ACTION_VIEW только для чтения, поэтому другое установленное аудиоприложение все еще может открыть файл.

Воспроизведение использует Media3 и может продолжаться в фоне. В Android 13+ разрешение уведомлений необязательно и влияет только на элементы управления в панели уведомлений. Отказ не препятствует воспроизведению.

Плагину требуется сборка AutoJs6 5269+. Он не содержит нативных библиотек и не зависит от ABI устройства.

Ограничения безопасности и конфиденциальности:

- Точка входа Проводника требует разрешения подписи AutoJs6 и проверяет протокол v2, оба content URI, ClipData, метаданные файла и права только для чтения.
- Независимая точка входа Android принимает только URI `content` для чтения с `audio/*` и не передает extras вызывающей стороны или широкие разрешения.
- Плагин не запрашивает разрешения хранилища или сети и никогда не записывает исходный файл.
- Совпадение расширения не гарантирует декодирование. Поддержка зависит от Media3, Android, кодеков устройства и содержимого файла.
- После ошибки декодера файл можно открыть в другом совместимом приложении, а этот плагин исключается из выбора.
