# 音频播放器

音频播放器为文件管理器已识别的以下音频扩展名提供应用内控制界面和后台播放:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave`

安装插件后, 对单个文件选择播放音频会从该曲目开始, 并可自动发现可读的直接同级音频, 按自然顺序组成有界队列. 显式选择 1 至 128 个文件并选择播放所选音频时, 仍保持宿主选择顺序. 缺少插件时, 宿主保留单文件只读外部 ACTION_VIEW 流程.

播放使用 Media3, 并可在后台继续. 播放器提供上一曲 / 下一曲, 可编辑队列, 顺序 / 随机 / 单曲循环, 睡眠定时器, A-B 区间循环, 倍速及逐曲续播. Android 13+ 通知权限是可选权限, 只影响通知栏控制.

同目录发现需要 AutoJs6 6.8.0 build 5276+ 及 Explorer Action v12; 后续插件能力不会提高此基线. 不提供可选会话能力的宿主仍仅播放所选文件.

安全和隐私限制:

- 文件管理器入口要求宿主签名权限, 并验证协议 v12, 有序目标与 ClipData, 标识符, 父子关系, 文件元数据, 声明的能力和只读授权.
- 独立 Android 入口仅接受面向 `audio/*` 的只读 `content` URI, 不会转发调用方 extras 或宽泛授权.
- 插件不请求存储或互联网访问权限, 也不会写入源文件. Media3 会合入普通权限 `ACCESS_NETWORK_STATE`, 但 APK 不含 `INTERNET` 权限.
- 请求级 Host Session 由宿主绑定到插件 UID, 仅允许非递归列出所选文件的直接父目录并打开所选文件或可读直接同级音频. 播放端只接收不透明合成路由, 不接收文件系统路径, 也绝不猜测同级 URI.
- 文件扩展名匹配不保证能够解码. 支持情况取决于 Media3, Android, 设备编解码器和文件内容.
- 解码错误后可使用其他兼容应用打开文件, 并在选择界面中排除本插件.
