# v1.4.0

###### 2026/08/29

* `Функция` Системное медиасообщение теперь содержит отдельные действия предыдущего и следующего трека, переключения перемешивания и выхода, а также прозрачный монохромный значок приложения; подсветка перемешивания синхронизируется с воспроизведением
* `Исправление` AutoJs6 больше не помечает плагин как ошибочный и не отключает его при обнаружении сведений о плагине и Explorer Action, поскольку два протокола Binder теперь используют отдельные службы
* `Исправление` Очистка очереди удаляет устаревшие сведения о треке и фоновый сеанс, отключает воспроизведение, поиск, очередь, скорость, таймер и A-B и показывает явное пустое состояние вместо обработки бесполезных нажатий
* `Исправление` Тень основной кнопки воспроизведения больше не обрезается нижней областью, а отключенное состояние использует отчетливые приглушенные цвета; переключатели, множественный выбор, прогресс и кнопки диалогов теперь следуют динамической теме
* `Улучшение` Приложение и плагин переименованы в непереводимое 3-Terra Player, а пространства имен и символы исходного кода переведены на формы three / Three; опубликованный ID приложения сохранен для обновлений и существующих настроек
* `Улучшение` Ярлык палитры на панели проигрывателя заменен меню из трех точек с единственным пунктом настроек без изменения существующего интервала под элементами воспроизведения

# v1.3.0

###### 2026/08/29

* `Функция` Добавлены экран запуска и автономный проигрыватель нескольких файлов, а также отдельные настройки языка, ночного режима, цвета темы, продолжения, обновлений, истории выпусков и сведений о приложении и разработчике
* `Функция` Язык, ночной режим и исходный цвет по умолчанию следуют AutoJs6 через официальный контракт только для чтения; если хост недоступен, варианты остаются видимыми, но отключёнными, и используются значения приложения
* `Функция` Добавлены ручная и ежедневная автоматическая проверка обновлений, управление игнорируемыми версиями и локализованная встроенная история выпусков
* `Исправление` Исправлено постоянное сообщение Host color unavailable: открыт защищённый вход службы информации о плагине, необходимый поставщику настроек хоста
* `Исправление` Действия Проводника теперь объявляют аудио MIME вместе с 19 известными расширениями, включая WMA, чтобы любой распознанный хостом аудиофайл сразу открывался в плагине
* `Улучшение` Продолжение запоминает ровно один последний открытый файл, немедленно удаляет старую запись при открытии другого и не сохраняет завершённое воспроизведение
* `Улучшение` Область метаданных стабильно занимает три строки и дополняет частоту и битрейт из выбранной дорожки в порядке 44.1 kHz · MP3 · 128 kbps
* `Улучшение` A-B теперь использует понятный цикл из трёх нажатий: задать A, задать B и очистить; нижние элементы получили отступ, одинаковый размер и точное вертикальное центрирование значков

# v1.2.2

###### 2026/08/27

* `Исправление` Воспроизведение из проводника больше не завершается ошибкой после обновления плагина, если запущенный файловый менеджер AutoJs6 всё ещё отправляет кэшированное действие протокола v4; шлюз принимает совместимый пакет только для чтения v4–v12 и по-прежнему объявляет v12
* `Исправление` Заявленные аудиорасширения больше не отклоняются, когда таблица MIME Android или производителя возвращает подстановочный либо application-тип; белый список расширений теперь предоставляет стабильный канонический аудио MIME-тип
* `Улучшение` Отклонённые запросы Explorer теперь записывают безопасный для конфиденциальности код причины без имён файлов, отображаемых путей и URI, что позволяет напрямую диагностировать будущие расхождения контракта

# v1.2.1

###### 2026/08/27

* `Функция` Действие «Воспроизвести аудио» для одного файла теперь обнаруживает через Explorer Action v12 до 128 читаемых аудиофайлов в той же папке и строит естественно отсортированную очередь с выбранной дорожки
* `Исправление` API 24 больше не отклоняет корректный запрос Explorer, когда Android добавляет из манифеста шлюзовой Activity не связанный с разрешениями флаг FLAG_ACTIVITY_EXCLUDE_FROM_RECENTS
* `Исправление` Автоматический переход к соседней дорожке больше не вызывает сбой при пересоздании обратного Intent MediaSession; исходно разрешённая цель остаётся якорем Host Session независимо от активного элемента очереди
* `Улучшение` Выбранная дорожка сохраняет исходный content URI, а соседние дорожки передаются только через файловые дескрипторы ограниченной запросом Host Session; URI не угадываются и не добавляется рекурсивный доступ, запись, доступ к хранилищу или постоянный доступ
* `Улучшение` Фильтрация аудиорасширений исключает из очереди видео .mp4 с тем же именем, что и аудио .m4a, а существующая явная очередь множественного выбора остаётся без изменений
* `Улучшение` Владение Host Session передаётся фоновой службе воспроизведения, которая закрывает её при замене очереди, ошибке запуска, завершении воспроизведения или уничтожении службы
* `Зависимость` Встроенный Explorer Action API обновлён с протокола v4 до обратно совместимого расширения v12 для чтения соседних файлов при сохранении минимальной сборки хоста 5276
