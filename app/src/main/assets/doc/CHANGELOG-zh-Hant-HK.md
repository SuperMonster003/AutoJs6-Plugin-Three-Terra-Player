### 版本記錄

******

# v1.5.0

###### 2026/08/31

* `新增` 專輯封面現在會為播放器漸變背景, 工具列, 控件及佇列即時產生易讀色板; 各頁面以邊到邊方式融入狀態列, 瀏海及手勢區域
* `新增` 播放設定新增可儲存的預設倍速, 5 / 10 / 15 / 30 秒快退快進步長, 以及佇列播完後停止, 返回佇列開頭並暫停或自動重播的行為
* `新增` 新增簡潔的播放 / 暫停及封面過場動畫, 並為主要播放操作加入遵從系統設定的觸感回饋; 系統關閉動畫時所有狀態直接切換
* `修復` 語言及夜間模式對話框的清單項目改用 16sp Material Body1, 不再沿用過大的平台清單文字
* `優化` 封面解碼及最大 64x64 取色樣本移至背景執行緒; 任何封面顏色繼續通過正文 4.5:1 及輪廓 3:1 的既有對比度門檻
* `優化` 完成播放視覺化可行性研究及 RMS 分桶原型: 平台 Visualizer 因要求錄音權限而繼續排除, 並記錄無權限 Media3 PCM 抽頭供日後效能基準驗證

# v1.4.1

###### 2026/08/31

* `新增` 獨立應用程式現在會在從啟動器再次開啟時還原上次佇列, 目前曲目, 停止位置, 循環模式, 隨機狀態及倍速; 還原後維持暫停, 且只儲存仍有長期唯讀授權的系統檔案選擇器佇列
* `修復` 修正播放器右上角更多選單在部分主題下出現白底白字, 無法辨認設定選單項目的問題
* `優化` 主題色設定中的 AutoJs6 來源統一表述為 `跟隨 AutoJs6`; 顏色選擇面板直接顯示宿主顏色的 HEX 值
* `優化` 完成十語言 README, CHANGELOG 及外掛程式說明的基本人工覆核, 並將專案主頁與應用程式內更新地址遷移至 3-Terra Player 正式儲存庫

# v1.4.0

###### 2026/08/29

* `新增` 系統媒體通知全面升級: 新增上一首 / 下一首 / 隨機播放開關與結束按鈕, 使用應用程式專屬的單色小圖示, 隨機狀態與播放器即時同步
* `修復` 修復外掛程式可能被 AutoJs6 外掛程式中心自動標記為錯誤並停用的問題: 外掛程式資訊與檔案管理器動作現在使用各自獨立的服務端點
* `修復` 清空播放佇列後不再殘留過期資訊: 介面進入明確的空狀態, 播放, 跳轉, 變速, 計時器與 A-B 等控制項同步停用
* `修復` 修復播放按鈕陰影被底部區域裁切的問題; 設定與更新對話框中的單選, 多選, 進度列與按鈕統一跟隨主題色彩
* `優化` 應用程式與外掛程式正式更名為 3-Terra Player: 應用程式 ID 保持不變, 可直接覆蓋安裝升級, 既有設定不受影響
* `優化` 播放器右上角選單精簡為只保留設定入口, 移除與設定頁重複的調色盤按鈕

# v1.3.0

###### 2026/08/29

* `新增` 新增獨立應用程式模式: 無需 AutoJs6 即可從啟動頁面一次選擇最多 128 個音訊檔案連續播放
* `新增` 新增設定頁面: 語言, 夜間模式, 主題色彩, 接續播放, 檢查更新, 發行記錄與應用程式資訊集中管理; 語言與外觀預設跟隨 AutoJs6, 主程式不可用時自動改用內置預設值
* `新增` 新增手動與每日自動檢查更新, 支援忽略指定版本, 並內置多語言發行記錄
* `修復` 修復主題色彩跟隨 AutoJs6 時一直提示主程式顏色不可用的問題
* `修復` 檔案管理器中所有被主程式辨識為音訊的項目 (新增 WMA) 現在都可以直接使用本外掛程式播放
* `優化` 接續播放只記住最近開啟的一個檔案: 開啟其他檔案或播放完畢後自動清除舊記錄
* `優化` 播放介面固定保留三行資訊區域並補足取樣率與位元率顯示, 切歌與非同步載入時版面不再跳動
* `優化` A-B 循環改為三次點按依次完成設 A 點, 設 B 點與清除; 底部控制區的間距與圖示對齊同步優化

# v1.2.2

###### 2026/08/27

* `修復` 修復覆蓋安裝新版外掛程式後, 檔案管理器中所有音訊都提示音訊要求無效的問題: 入口現在兼容執行中主程式快取的舊版唯讀要求
* `修復` 修復部分裝置 MIME 表異常導致 `ogg`, `opus` 等已支援副檔名被誤拒的問題: 由副檔名白名單提供穩定的規範音訊類型
* `優化` 要求被拒絕時輸出私隱安全的原因碼日誌 (不含檔案名稱, 路徑與 URI), 方便回報與定位問題

# v1.2.1

###### 2026/08/27

* `新增` 從檔案管理器開啟一首歌時, 自動尋找同一資料夾的其他音訊並按檔案名稱自然排序連播: 最多 128 首, 從所選曲目開始
* `修復` 修復 Android 7.0 裝置上系統自動附加的視窗標誌導致合法播放要求被誤拒的問題
* `修復` 修復自動切換到同一資料夾曲目時可能崩潰的問題
* `優化` 同目錄尋找全程唯讀且有界: 不遞迴子資料夾, 不猜測檔案位置, 不要求儲存權限, 與音訊同名的影片檔案不會進入佇列
* `優化` 同目錄讀取工作階段交由背景播放服務持有, 並在佇列被取代, 播放完成或服務銷毀時自動關閉
* `依賴` 內置檔案管理器動作介面升級至向後兼容的 v12, 最低主程式版本保持 build 5276

# v1.2.0

###### 2026/08/27

* `新增` 新增多選播放: 在檔案管理器中勾選最多 128 個音訊一鍵加入佇列, 嚴格保持勾選次序

* `優化` 系統媒體控制新增上一首, 下一首與快退快進 10 秒命令, 通知中繼資料隨佇列切換即時更新
* `優化` 檔案管理器要求驗證擴展到有序多選目標, 繼續保持最小唯讀授權
* `依賴` 檔案管理器動作介面從 v2 升級至 v4, 最低主程式版本提升至 build 5276

# v1.0.0

###### 2026/08/02

* `新增` 首個正式版本: 為 AutoJs6 檔案管理器提供播放音訊動作, 涵蓋 18 種常見音訊副檔名, 點按即可播放
* `新增` 基於 Media3 ExoPlayer 與 MediaSessionService 的穩定播放: 支援背景播放, 音訊焦點管理, 輸出裝置中斷自動暫停與系統媒體控制

* `新增` 嚴格的安全基線: 不要求儲存與互聯網權限, 只接受並轉交最小唯讀授權
* `新增` 外掛程式資訊, 使用說明, README 與更新記錄涵蓋 10 種語言
* `依賴` 新增 AndroidX Media3 ExoPlayer, Session 與 UI 1.10.1
