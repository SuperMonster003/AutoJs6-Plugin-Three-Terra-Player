# 音訊播放器

音訊播放器為檔案管理器已辨識的以下音訊副檔名提供應用程式內控制介面和背景播放:

`aac, ac3, amr, awb, flac, m4a, m4b, m4r, mka, mp1, mp2, mp3, mpga, oga, ogg, opus, wav, wave`

安裝外掛程式後, 對單一檔案選擇播放音訊會從該曲目開始, 並可自動尋找可讀的直接同級音訊, 按自然次序組成有界佇列. 明確選取 1 至 128 個檔案並選擇播放所選音訊時, 仍保持主程式選取次序. 缺少外掛程式時, 主程式保留單一檔案唯讀外部 ACTION_VIEW 流程.

播放使用 Media3, 並可在背景繼續. 播放器提供上一首 / 下一首, 可編輯播放佇列, 順序 / 隨機 / 單曲循環, 睡眠計時器, A-B 區間循環, 倍速及逐曲續播. Android 13+ 通知權限是可選權限, 只影響通知欄控制.

同目錄尋找需要 AutoJs6 6.8.0 build 5276+ 及 Explorer Action v12; 後續外掛程式功能不會提高此基線. 不提供可選工作階段功能的主程式仍只播放所選檔案.

安全和私隱限制:

- 檔案管理器入口要求主程式簽名權限, 並驗證通訊協定 v12, 有序目標與 ClipData, 識別碼, 父子關係, 檔案元資料, 宣告功能和唯讀授權.
- 獨立 Android 入口只接受面向 `audio/*` 的唯讀 `content` URI, 不會轉交呼叫端 extras 或廣泛授權.
- 外掛程式不要求儲存空間或互聯網存取權限, 也不會寫入來源檔案. Media3 會加入普通權限 `ACCESS_NETWORK_STATE`, 但 APK 不含 `INTERNET` 權限.
- 要求級 Host Session 由主程式綁定至外掛程式 UID, 只允許非遞迴列出所選檔案的直接上層目錄並開啟所選檔案或可讀直接同級音訊. 播放端只接收不透明合成路由, 不接收檔案系統路徑, 亦絕不猜測同級 URI.
- 檔案副檔名比對不保證可以解碼. 支援情況取決於 Media3, Android, 裝置編解碼器和檔案內容.
- 解碼錯誤後可使用其他相容應用程式開啟檔案, 並在選擇介面中排除本外掛程式.
